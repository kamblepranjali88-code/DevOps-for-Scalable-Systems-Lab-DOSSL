# Assignment 2: Git Branching and Collaboration

## Aim
To demonstrate Git branching and collaborative development practices by managing feature changes separately and integrating them into the main project using GitHub.

## Objectives
- Understand the role of branches in version control.
- Create and manage a feature branch.
- Make and commit changes independently of the main branch.
- Publish a feature branch to GitHub.
- Understand Pull Requests and code review.
- Integrate feature changes into the main branch.
- Verify repository synchronization and commit history.

## Tools and Technologies
- **Git:** Tracks changes and manages project versions.
- **GitHub:** Hosts the remote repository and supports collaboration.
- **Visual Studio Code:** Used to edit files and execute Git commands.
- **HTML, CSS, and JavaScript:** Technologies used in the Student Task Manager application.

## Introduction
Git branching allows developers to work on new features without directly modifying the main version of a project. Each branch provides an independent workspace for changes, which can be committed and shared before being integrated into the main branch.

In this assignment, branching concepts are applied to the Student Task Manager Web Application.

## Procedure
1. Open the project repository and check its current status.
2. Synchronize the local `main` branch with GitHub.
3. Create a separate feature branch for an application improvement.
4. Modify the application while working on the feature branch.
5. Stage the modified files and create a commit.
6. Push the feature branch to the remote repository.
7. Create a Pull Request on GitHub when ready to propose integration.
8. Review the proposed changes and merge them when appropriate.
9. Synchronize the local `main` branch after merging.
10. Verify the final repository status and commit history.

## Conclusion
Branching is an important version-control practice that allows developers to work independently while keeping the main project organized. Combining Git branches with GitHub Pull Requests provides a structured workflow for reviewing and integrating changes.
