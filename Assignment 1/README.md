# Assignment 1: Git Basics and Version Control

## Aim
To create and manage a GitHub repository for the Student Task Manager Web Application and demonstrate basic Git and GitHub version control operations.

## Objectives
- Create a GitHub repository for the project.
- Track and manage application files using Git.
- Commit changes and maintain version history.
- Push and pull changes between the local repository and GitHub.
- Create and switch between branches.
- Merge feature branches into the main branch.
- Verify commits and repository history.

## Tools and Technologies Used
- **Git** – Version control system.
- **GitHub** – Remote repository hosting.
- **Visual Studio Code** – Code editor.
- **HTML** – Application structure.
- **CSS** – Application styling.
- **JavaScript** – Application functionality.

## Project Description
The Student Task Manager is a web application that helps students organize and manage their tasks. Users can add tasks, specify due dates, filter tasks, mark tasks as completed, and delete tasks. The application uses browser local storage to retain task data.

## Git Operations
The following Git and GitHub operations are covered in this assignment:

1. Created a GitHub repository for the project.
2. Organized the application files in the `Assignment 1` folder.
3. Added and committed project files.
4. Pushed changes to the GitHub repository.
5. Created a feature branch named `feature-ui`.
6. Made changes to the application on the feature branch.
7. Committed and merged changes into the `main` branch.
8. Pulled the latest changes and reviewed the commit history.

*Note: Keep only the operations you have actually completed in this list.*

## Project Files
- `index.html` – Defines the application's structure.
- `style.css` – Contains the application's styles.
- `script.js` – Implements task management functionality.
- `README.md` – Documents the assignment.
- `screenshots/` – Stores screenshots showing the project and Git operations.

## Outcome
The Student Task Manager Web Application was organized in a GitHub repository to demonstrate basic Git and GitHub version control concepts, including tracking changes, committing files, branching, merging, and maintaining project history.
