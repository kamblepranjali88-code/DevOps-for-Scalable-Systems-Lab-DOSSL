# Assignment 1: Git Basics and Version Control

## Aim
To understand Git and GitHub and practice basic version control operations using a Student Task Manager web application.

## Project Files
- `index.html` — HTML structure of the application.
- `style.css` — Application styling.
- `script.js` — Task management functionality.

## Features
- Add student tasks.
- Set task due dates.
- Track task progress.
- Mark tasks as completed.
- Filter tasks by status.
- Delete tasks.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Result
The Student Task Manager application is prepared for demonstrating Git and GitHub version control operations.
