## 📌 About This Repository

This repository serves as the practical lab work record for the **DevOps for Scalable Systems Lab (DOSS)**. It contains assignment files, configuration files, commands, and practical evidence related to the concepts covered in the course.

The common project is a **Student Task Manager web application**, which provides a practical foundation for exploring DevOps tools, deployment workflows, automation, and application monitoring.

## 🧪 Assignments and Topics

| Area | Concepts Covered |
|---|---|
| 🔀 Version Control | Git, GitHub, branching, and collaboration |
| 🐳 Containerization | Docker images, containers, and application packaging |
| ⚙️ CI/CD | Jenkins build automation, pipelines, and automated testing |
| ☸️ Orchestration | Kubernetes, Minikube, Deployments, Services, scaling, and self-healing |
| 📊 Monitoring | Prometheus metrics collection and PromQL queries |
| 📈 Visualization | Grafana dashboards and application performance metrics |

Each assignment contains relevant implementation files, configuration files, commands, and practical evidence, as applicable.

## 🔄 DevOps Workflow

The project explores the following general workflow:

**Source Code → GitHub → Jenkins Pipeline → Docker Image → Kubernetes Deployment → Prometheus Monitoring → Grafana Dashboard**

The actual level of automation depends on the configuration implemented in each assignment.

## 🛠️ Technology Stack

- **Application:** Student Task Manager
- **Programming:** HTML, CSS, JavaScript, and Node.js where required
- **Version Control:** Git and GitHub
- **Containerization:** Docker
- **CI/CD:** Jenkins
- **Orchestration:** Kubernetes and Minikube
- **Monitoring:** Prometheus
- **Visualization:** Grafana
- **Configuration:** YAML

## 🎯 Objective

To gain hands-on experience with DevOps principles and tools by implementing a structured workflow covering source code management, containerization, CI/CD automation, application deployment, scaling, and monitoring.
